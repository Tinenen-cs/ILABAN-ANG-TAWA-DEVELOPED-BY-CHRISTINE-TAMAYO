# Character design notes (original chibi adults)

Reference photos in `CHARACTER REFERENCE` were used ONLY for expression type, pose energy, hair silhouette,
clothing and accessories. No face or likeness is traced or reproduced; nobody is identified. Every face below is an
original design with deliberately different face shape, eyes and nose. All 8 are ageless chibi ADULTS (2.2 heads tall,
adult proportions in torso/limbs, no child features). Style: clean dark outline, flat 2-tone shading, slightly pixelated.
